# Chapada Diamantina Oficial — site

Site institucional da **Chapada Diamantina Oficial** (@chapada_diamantina_oficial), do guia **Wendell Junior**.
Desenvolvido pela **TS Digital** (Seabra/BA).

## Como funciona

- Site estático em um único arquivo: `index.html` (HTML + CSS + JavaScript, com as fotos embutidas).
- Não usa banco de dados nem servidor: os botões de agendamento montam a mensagem e abrem o WhatsApp do guia.
- **Deploy:** importar este repositório no Vercel — cada push novo atualiza o site automaticamente.
- Domínio próprio será apontado para o Vercel quando for comprado.
